# 双硬盘 双系统
## 背景

首先，我安装 Linux 的目的是为了复现一个深度学习工程。因此如果有一些出入，那么我认为因项目而异，在跟随这个攻略之前，要确认自己的需求。

计算机系统的硬件列表如下： 
 - **Processor** : 12th Gen Intel Core i5-12400F
 - **Mem** :  16GB
 - **Graphics** : Nvdia RTX3060 12GB
 - **System** : x64
 - **Mother Board** : GIGABYTE AOROUS B660i 

在这个基础上，我的主板只有一个硬盘位，但是我是使用了一个移动硬盘（里面装着 SSD），来当做 Ubuntu 的系统盘。

主板是貌似支持引导系统的，所以安装好之后，可以识别到不同的 EFI 分区的硬盘，所以目前是不需要担心这个问题。

## Linux 安装前准备工作

我安装的是 **Linux Ubuntu 20.04LTS** 版本，选择这个版本一部分原因是因为 Ubuntu 系统用的人多，后续支持也比较好，支持的驱动也比较全，不需要考虑太多的东西。

并且我想要下载的 **cuda**版本明确规定了这个 Linux 版本（*顺带说一句，不是很理解现在科研使用的环境版本实在是太旧了。这就跟我在公司用的是 VS2022，但是学校还在使用 VB 一样，就是因为版本太旧了，所以当时在开发的过程中，还要下载一堆VS 旧版本支持*），所以最终还是选择了这个版本。

> 其实我一开始下载的是 24 版本的 Ubuntu，但是就是因为这个 Cuda 版本要求，最终还是重新安装了，不然可能这个文档都不会存在，哈哈哈。

言归正传，我们在安装 Linux 之前准备以下事情物件: 
 - 一个 8GB~32GB 大小 U 盘
 - **Rufus** ——启动盘设置软件
 - Ubuntu 20.04 LTS x64 版本的 iso
 - Qwen（随便一个大语言模型均可）
  
ok 准备好了这些工具，基本上我们就可以开始了。最后一个是为了如果你在安装过程中有问题，那么你就可以询问一下，我自认为比百度、Bing 好用百倍。

## 第一步：设置启动盘

上面提到的东西都是可以在官网下载，在下载 iso 时，就是要注意一下你的CPU 架构，比如说我是 x64，某些人是 x86，也就是 32 位CPU，那么就需要下载 x86 版本（*20.04 LTS因不再支持 x86，所以没有这个版本，但是现在应该大部分的 PC 都是 64 位*）。

然后打开 Rufus 软件，设置好后直接点击开始，等待下方绿色条读完，就完成了启动盘设置。

> 补充一下，我们设置启动盘的这个 U 盘，如果是你用过，是需要备份一下。其次，U 盘格式我设置的是 UTFS，不知道这个格式会不会有影响，但是实测可以用。

等待启动盘设置过程中（*这个时间会比较长*），我们需要处理一下系统盘，就是我们想要安装 Ubuntu 的位置。选择这个硬盘后，将其删除卷，就是删掉这个硬盘所有的东西。硬盘删除工具一般 Windows 都会有，删除正确的话，就是一整片黑白的状态。


## 第二步：安装Ubuntu

完成启动盘设置之后，就一直插着，不要拔下来，系统重启一下，然后进入 BIOS界面。进入 BIOS 界面之后，关闭安全模式，然后将U 盘设置为第一顺位。然后你可以顺便记一下你的硬盘名称，在 windows 中可以使用diskpart 来看一下。最后，就可以重启，这会就不需要进入 BIOS 了，主板可能会打开引导界面，然后选择 “Ubuntu“，按下键盘“Enter“键。

> BIOS 中 U 盘对应的盘可能会有多个分区，那么你就选择第一个分区即可。因为第一个一般就是 EFI 分区。

> 如果没有打开引导界面，那么你进入 BIOS 检查一下，Ubuntu 系统是不是在硬盘第一顺位。如果在第一顺位却仍然没有打开引导界面，这个分享就不适合你了，以为超出了我的认知。

然后安装肯定大家都是会的，其中需要注意的是，如果你想装双硬盘双系统（*一个硬盘装一个系统*），那么你需要在过程中选择，删除所有那个选项。在这个步骤中，一定要看准你要把 Ubuntu 安装在哪一个硬盘，否则就等着哭吧。

其次，可以先不要让系统先下载必要相关的驱动，因为就算你不下载也是可以正常进入系统的（*30 系以上的显卡可能不会，所以 30 系显卡以上的的 PC 用户可以先安装*）。或者你不放心的话，也可以安装，后面你可以卸了重装。

安装完成之后，系统会让你重启，然后顺带还有一些系统软件更新，一阵重启之后，算是可以正常进入系统了。这时候，你可以尝试重启一下，查看是否可以进入引导界面，查看是否有 windows 的选项，如果都有，那么就算是大功告成了。方便的时候，可以进入 BIOS，把安全模式关闭，U 盘拔掉。


## 一些问题
### 1、如果你在这个硬盘里已经安装了 Linux，然后发现安装错误版本了，需要重装怎么办？

到了这一步，你肯定已经红温了，但是不要急，是有方法的，发现地越早，你就越......没那么痛苦。

处理方法也很简单，在双硬盘双系统的情况下，你可以回到 windows 系统，来处理。进入磁盘管理工具，把安错的分区删掉，没其他问题的话，应该还剩下一个 EFI 分区。这个分区在 windows 系统下，是删不掉的（*在这个 windows 管理软件中*）。然后你以管理员身份打开 powershell，遵循以下步骤，将这个分区强行删除掉：

#### 1. 启动 diskpart 工具
在命令行中输入以下指令，然后回车：

```py title="cmd"
diskpart
```

#### 2. 选择你的硬盘
在命令行中输入以下指令，然后回车：

```py title="cmd"
list disk
```

然后选择你要处理掉的硬盘（*以我要删除 disk1 为例*）：

```py title="cmd"
select disk 1
```

#### 3. 选择分区，并删除
首先清除只读属性：

```py title="cmd"
attributes disk clear readonly
```

然后列出该硬盘上所有的分区：

```py title="cmd"
list partition
```

然后选择之（*以我要删除 partition 0 为例*）：

```py title="cmd"
select partition 0
```


然后删除之（*以我要删除 partition 0 为例*）：

```py title="cmd"
delete partition override
```

#### 4. 验证你的删除操作
验证一下：

```py title="cmd"
list partition
```

做完这些操作，exit 退出即可完成。进入 windows 自带的工具，你就会发现你的硬盘回到了当初灰白的模样。

### 2、chrome 浏览器咋安装
在国内，Ubuntu 系统中，你大概率进不去 chrome 的官网。但庆幸，chrome 可以在 bash 中下载完成。
遵循以下步骤，就可以完成安装了：

#### 1. 导入 Google 的公钥

```py title="bash"
wget -q -O - https://dl.google.com/linux/linux_signing_key.pub | sudo apt-key add -
```

#### 2. 添加 chrome 浏览器的 deb 软件源

```py title="bash"
sudo sh -c 'echo "deb [arch=amd64] http://dl.google.com/linux/chrome/deb/ stable main" >> /etc/apt/sources.list.d/google-chrome.list
```

#### 3. 更新软件包列表并下载之

```py title="bash"
sudo apt-get update
sudo apt-get install google-chrome-stable
```


# cuda 11.3 Toolkit 安装
## 背景

安装 cuda 驱动真的是一波三折，由于版本太老了，并且过程中 DEBUG 过程有些没有逻辑性了，所以如果说按照以下步骤没有实现也是很有可能的。

计算机系统的硬件列表如下： 
 - **Processor** : 12th Gen Intel Core i5-12400F
 - **Mem** :  16GB
 - **Graphics** : Nvdia RTX3060 12GB
 - **System** : x64
 - **Mother Board** : GIGABYTE AOROUS B660i 

要有一些前提，就是我在我的 windows 系统下已经安装了 nvidia 的驱动了，所以在 ubuntu 系统下，安装完 nvcc 之后，输入 nvidia-smi 会显示 cuda 版本不是对应的。

这个情况也是正常的，我们现在要下载的是 Toolkit，上面的指令显示的是你的驱动程序支持的 cuda 可运行的最高版本。这个情况我们后面再处理，先将其安装好。

## 第一步：尝试官方下载方法
我们直接寻找**nvidia**官方下载方案，如果下载成功了，那么就没有剩下的事情了。但是我估计大概率不会成功的，因为在下载 cuda toolkit 时，最终解析的时候，linux 自带的内核版本要偏高，是无法继续执行下去的。大概率会遇到以下的报错：

```py title="bash"
dpkg: error processing package nvidia-dkms-465 (--configure): installed nvidia-dkms-465 package post-installation script subprocess returned error exit status 10
```

那么我们就可以进入第二步骤了。

## 第二步：安装 nvidia-driver-535-open

首先我们先要将 465 的版本删除掉，这里建议直接使用Qwen 来引导你写 bash 指令。然后我们再安装这个版本：

```py title="bash"
nvidia-driver-535-open
```

open 版本会更加稳定，因为是开源。

然后我们就可以按照 Qwen 给的步骤一步一步安装下去。由于这个包一般是不允许用户自己安装的，所以我们记得要让 apt 自己 upgrade 以下， 或者说，重新建立依赖关系。具体步骤我就不贴出来了，现在的语言模型应该都会教你去做这件事情。

## 第三部：处理图形驱动的问题

可能你重启之后，会遇到一些问题，例如，nvcc 识别不到；显示分辨率非常低，并且 nvidia-smi 也没有反应。

那么你可以做以下步骤来完善最后的安装：
- 关闭 BIOS 中的安全模式
- 将nouveau 或者 vesa 驱动屏蔽掉

关闭 BIOS 安全模式，是为了防止有些未签名模块被阻止加载。将 nouveau 驱动屏蔽掉是因为会和 nvidia 驱动冲突，所以我们需要将其屏蔽掉。这样你的分辨率、sudo apt upgrade、nvidia-smi 应该都好使了。nvidia-smi 这个问题也有可能是因为你的环境变量中没有添加进去 nvidia 驱动。

做完这些步骤你可以 nvidia-smi 验证一下。这时候就可能会遇到我上面那个问题，就是显示的 cuda 版本号不同。这个情况一般是正常情况，也不会存在冲突的，就相当于你下载了很多的 python 版本，不会冲突的一般来说。等后面我们开发的时候可以再去考虑如何切换或者是使用这个 Toolkit。
